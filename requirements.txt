# Dependencias de Digilogic Player.
#
# Instalación desde cero:
#     python3 -m venv venv
#     ./venv/bin/pip install -r requirements.txt
#     ./venv/bin/python Digilogic.py

# Toda la interfaz: ventana, audio (QMediaPlayer), dibujo y animaciones.
PyQt6>=6.11.0

# Lee las etiquetas y la portada incrustadas en los MP3. El reproductor
# funciona sin ella (usa el nombre del archivo como título y muestra la
# nota animada en vez de la portada), pero se pierden ambas cosas.
mutagen>=1.48.1

# Integración con el centro multimedia de macOS: hace que las teclas de
# reproducción del teclado lleguen a Digilogic aunque la ventana esté
# detrás, y que la canción salga en el Centro de Control, en la pantalla
# bloqueada y en los AirPods.
#
# Opcional de verdad: el reproductor arranca y funciona igual sin ella,
# solo pierde eso. Va con marcador de plataforma porque en Windows no
# existe ni hace falta.
pyobjc-framework-MediaPlayer>=10.0 ; sys_platform == "darwin"

# Solo para empaquetar. No hacen falta para ejecutar Digilogic desde el
# código, y cada una sirve para un sistema:
#   - macOS:   python setup.py py2app
#   - Windows: python construir_windows.py
#
# Van con marcador de plataforma: pip instalará únicamente la que
# corresponda al sistema donde se ejecute.
py2app>=0.28.10 ; sys_platform == "darwin"
pyinstaller>=6.0 ; sys_platform == "win32"
